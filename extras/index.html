Instructions for Using the Script in Google Colab

  1. Accessing the Script:

    • The code available at https://github.com/Jodavid/ml_ia_codes can be viewed directly in Google Colab.
    • Important: The notebooks will be opened in view-only mode and cannot be executed directly.

  2. Creating a Copy:

    • To use any notebook, create a copy in your personal or institutional Google Drive.

    • Follow these steps to copy the notebook:

      1. Click File in the top menu.
      2. Select Save a copy in Drive.
      3. Choose the destination folder in your Google Drive.
      4. Once the copy is created, you will be able to edit and run the notebook freely.

  3. Using the Notebook:

    • After creating a copy, you can run the script directly from your Google Drive.
    • Make sure that all file paths and permissions are configured correctly.
