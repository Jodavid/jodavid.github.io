Google Colab Usage Guide

  1. Accessing the Notebooks:

    • The teaching code repository at https://github.com/Jodavid/ml_ia_codes can be launched directly into Google Colab.
    • Notebooks open in view-only mode by default.

  2. Creating an Executable Copy:

    • In Google Colab, navigate to File → Save a copy in Drive.
    • Select your personal or institutional Google Drive directory.
    • The copy is now fully interactive and ready to execute or modify.

  3. Running the Code:

    • Connect to a runtime (CPU/GPU as needed) and execute cells sequentially.
